# Vocabee — trang công khai (tạm thời)

Chính sách bảo mật, hỗ trợ và yêu cầu xoá tài khoản cho app **Vocabee: Học Tiếng Anh**
(Google Play / App Store). Đăng bằng GitHub Pages qua Actions (`.github/workflows/pages.yml`),
sau này chuyển sang vocabee.vn.

- `site/privacy/` — Chính sách bảo mật
- `site/support/` — Hỗ trợ
- `site/delete-account/` — Yêu cầu xoá tài khoản (link "Account deletion" của Google Play)

Sửa nội dung trong `site/` rồi push lên `main` là tự đăng lại.
